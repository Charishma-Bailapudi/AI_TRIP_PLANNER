# Epic 11: AI Agent Orchestration

## Goal

Coordinate specialized AI agents to build optimized travel plans.

### Features

* Segment Builder Agent
* Flight Search Agent
* Train Search Agent
* Connectivity Agent
* Budget Agent
* Itinerary Agent
* Recommendation Explanation Agent

### Success Criteria

The orchestrator agent seamlessly manages the flow of inputs and queries across specialized subagents, building complete multi-city routes and itineraries with explainable justifications.
